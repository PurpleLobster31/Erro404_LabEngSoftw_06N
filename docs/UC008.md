# Especificacao de Caso de Uso: UC008

## Informações Gerais

| Campo | Conteúdo |
| :--- | :--- |
| **Identificador** | UC008 |
| **Nome** | Pesquisar Hospitais |
| **Atores** | Paciente |
| **Sumario** | O paciente realiza uma busca textual para encontrar um hospital especifico. O resultado e uma lista filtrada de unidades carregadas da API. |
| **Pre-condicao** | A lista de unidades foi carregada pelo frontend. |
| **Pos-condicao** | O paciente visualiza os dados e tempos de espera das unidades filtradas. |
| **Pontos de Inclusão** | UC001 - Verificar Tempo em Pronto Atendimento |
| **Pontos de Extensão** | |

---

## Fluxo Principal

| Acoes do Ator | Acoes do Sistema |
| :--- | :--- |
| 1. O paciente acessa a funcionalidade de pesquisa de hospitais. | |
| | 2. O aplicativo exibe um campo de busca textual. |
| 3. O paciente insere o nome do hospital específico desejado e aciona o botão "Buscar". | |
| | 4. O sistema filtra localmente a lista de unidades por nome e endereco. |
| | 5. O sistema atualiza a interface, exibindo apenas as unidades correspondentes. |

---

## Fluxo Alternativo: Busca sem resultados

| Acoes do Ator | Acoes do Sistema |
| :--- | :--- |
| 1. O paciente aciona o botão "Buscar" com um termo específico. | |
| | 2. O sistema nao identifica nenhuma unidade correspondente ao termo na lista carregada. |
| | 3. O aplicativo exibe uma mensagem informando que nenhum hospital foi encontrado. |
| | 4. O campo de busca é mantido disponível para a inserção de um novo termo. |

---

## Fluxo de Excecao 1: Indisponibilidade do servico de busca

| Acoes do Ator | Acoes do Sistema |
| :--- | :--- |
| | 1. O sistema nao consegue carregar a lista de unidades da API. |
| | 2. O aplicativo exibe uma mensagem de erro e a busca fica indisponivel ate nova tentativa. |
